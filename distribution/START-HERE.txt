GTAV MOBILE — v0.1.0-alpha.1
Android + iOS, with automatic game setup from playgta5.
Experimental: builds are checked; real-device gameplay is not yet verified.

ANDROID
1. Open gtav-mobile-android.apk on your phone and allow installation when asked.
   Or connect one unlocked phone by USB and run Install-Android.cmd (Windows)
   or Install-Android.command (Mac). Enable USB debugging and trust the computer.
2. The USB helpers use Google's Platform-Tools. If missing, download them from
   https://developer.android.com/tools/releases/platform-tools
   and extract the platform-tools folder beside the helper.
3. Open GTAV Mobile, tap Download game, and keep the app open until setup ends.
   Tap Play. First launch compiles the game and may take several minutes.

Requires ARM64, Android 9+ and Vulkan 1.1. High-memory devices recommended;
minimum RAM and supported devices have not been established.
Mac terminal alternative: bash Install-Android.command

IPHONE / IPAD
GTAVMobile-ios.ipa includes the precompiled game executable.
Install it using AltStore Classic and your own Apple account:
Mac: https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos
Windows: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

Connect your phone, trust the computer, and follow that guide to install AltStore.
Import GTAVMobile-ios.ipa using My Apps +. Enable Developer Mode when required.
Then open GTAV Mobile, tap Download game, keep it open until setup ends, and Play.

The IPA must be re-signed for your phone; simply copying it by USB cannot install
it. Free-account signing requires periodic refresh. iOS 15+; an 8 GB RAM device
is recommended by the original runtime. Memory limits depend on device/signing,
and this build has not been gameplay-tested on a phone.

GAME SETUP
Use Wi-Fi. First setup downloads about 17 GB and installs about 16 GB.
Allow at least 19 GB free, plus extra space for Android's compiled game cache.
Both apps fetch pinned archives from alihammoud21/playgta5, verify SHA-256 hashes,
and save completed parts. If interrupted, tap Download game to resume; only the
unfinished part restarts. After setup, single-player data is available offline.
The desktop ZIP contains the apps and USB helpers; the game data downloads on
the phone during first setup. It is not a 17 GB offline installer.
Uninstalling the app removes its private game files and saves.
